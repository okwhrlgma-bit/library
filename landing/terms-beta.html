kormarc-auto 베타 약관

서비스 이용 약관·개인정보 처리방침·환불 규정·데이터 보안 정책

최종 갱신: 2026-05-09 · 본 약관은 베타 운영 기간 한정 적용

📌 베타 한정: 본 약관은 베타 운영 기간 (정식 런칭 전) 동안 적용됩니다. 베타 사용자는 정식 런칭 시 Founding Member 영구 50% 할인이 자동 적용됩니다.

제1조 (목적)

본 약관은 kormarc-auto (이하 "서비스")의 베타 운영 기간 동안 사서 및 도서관 운영자(이하 "이용자")가 서비스를 이용함에 있어 권리·의무·책임 사항을 규정함을 목적으로 합니다.

제2조 (서비스의 내용)

  1. 한국 도서관 KORMARC 자동 생성 SaaS (KOLAS III·정보누리·책이음·독서로·알파스 호환)
  2. ISBN·책 사진·키워드 입력 → MARC + .mrc 파일 자동 생성
  3. 9 자료유형 지원 (단행본·연속간행물·비도서·고서·전자책·전자저널·오디오북·멀티미디어·학위논문)
  4. 사서 검토 우선 원칙 (AI는 후보만 제시·사서 결정 영역 침범 X)

제3조 (베타 운영 기간 한정 조항)

  • 베타 기간 = 무료 평가판 50건 (가입 즉시·결제카드 등록 X)
  • 서비스 안정성·정합률 = 자관 174건 4단 검증 99.8% 정합 (상황 따라 변동 가능)
  • 정식 런칭 시 가격 변경 가능 (최소 30일 전 사전 고지)
  • 베타 사용자 = Founding Member 영구 50% 할인 자동 적용
  • 베타 운영 기간 = 정식 런칭 시점 (별도 고지) 까지

제4조 (이용자의 의무)

  1. 이용자는 정확한 정보 (이메일·도서관명)를 제공해야 합니다
  2. 발급받은 API 키·라이선스 키는 안전하게 보관하며, 제3자에게 공유하지 않습니다
  3. 서비스를 불법·악의 목적으로 사용하지 않습니다 (저작권 침해·스팸 등)
  4. 대량 자동 호출 시 사전 협의 필요 (시간당 1,000건 초과)

제5조 (운영자의 의무)

  1. 서비스의 지속적·안정적 운영을 위해 노력합니다
  2. 이용자의 개인정보 보호 (제8조 정합)
  3. 서비스 장애 시 빠른 복구 및 사전·사후 고지
  4. 외부 API (NL Korea·알라딘) 데이터 정합 모니터링

제6조 (환불 규정)

전자상거래법 §17 및 대법원 판례 정합:

  • 결제 후 7일 + 사용 30% 이하: 전액 환불
  • 결제 후 7일 + 사용 30% 초과: 부분 환불 (사용분 차감)
  • 결제 후 7일 초과: 환불 거부 (단, 서비스 결함 시 별도)
  • 환불 요청: 이메일 또는 사이트 채팅·24시간 내 회신

제7조 (데이터 보안 — 헌법 §14)

🔒 중요: 사서 데이터 (자관 KORMARC·.mrc·이용자 정보)는 사서 컴퓨터에만 저장되며, 서비스 서버에 저장되지 않습니다.
  • 이용자 데이터 = 사서 PC·SaaS 서버 저장 X (헌법 §14)
  • 외부 API 호출 = ISBN·검색어 등 비식별 정보만 전송
  • 암호화: TLS 1.2+·bcrypt·AES-256
  • 72시간 신고 자동화 (PIPA 시행 2026-09-11 정합)
  • audit log + 해시 체인 (5만명+ 또는 민감정보 처리 시)

제8조 (개인정보 처리)

「개인정보 보호법」 (PIPA) 정합 5대 패턴:

  1. 수집 항목: 이메일·도서관명·결제 정보 (PG사 위탁)
  2. 이용 목적: 서비스 제공·결제·고객 응대·서비스 개선
  3. 보유 기간: 회원 탈퇴 시 즉시 삭제·결제 기록 = 5년 (전자상거래법)
  4. 제3자 제공: PG사 (Polar.sh·LemonSqueezy·PortOne v2·결제 처리 한정)
  5. 이용자 권리: 열람·정정·삭제·처리 정지 (개인정보 보호법 §35~37)

제9조 (지적재산권)

  • 서비스의 코어 엔진 = Apache 2.0 라이선스 (오픈 소스)
  • SaaS 부가 서비스 (UI·결제 통합·운영 인프라) = 상용 라이선스
  • 사서 입력 데이터 (KORMARC·.mrc) = 이용자 소유·서비스는 가공 권한만

제10조 (서비스 변경·중단)

  1. 운영자는 사전 고지 후 서비스 일부 변경·중단할 수 있습니다 (최소 7일)
  2. 긴급 보안·법적 조치 시 사전 고지 없이 즉시 변경 가능
  3. 서비스 영구 종료 시 30일 전 고지 + 데이터 export 지원

제11조 (책임 한계)

  • 천재지변·전쟁·통신 장애 등 불가항력 사유로 인한 손해 = 운영자 책임 X
  • 이용자 부주의 (API 키 분실·계정 도용 등) = 운영자 책임 X
  • 외부 API (NL Korea·알라딘 등) 장애 시 = 임시 demo mode 자동 전환
  • AI 추천 결과 = 사서 검토·결정 영역·최종 책임은 사서에게 있음

제12조 (분쟁 해결)

  1. 본 약관은 대한민국 법령에 따라 해석됩니다
  2. 분쟁 발생 시 양 당사자는 우선 협의·조정으로 해결을 시도합니다
  3. 소송 관할 법원 = 서울중앙지방법원

제13조 (약관 변경)

  • 운영자는 약관을 변경할 수 있으며, 최소 30일 전 서비스 내 공지
  • 이용자는 변경 약관에 동의하지 않을 경우 회원 탈퇴 가능
  • 30일 후 계속 이용 = 변경 약관에 동의한 것으로 간주
