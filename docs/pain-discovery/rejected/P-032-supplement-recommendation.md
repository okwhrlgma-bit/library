# P-032: 영양제 추천 (NO_GO)

> 작성: 2026-05-09 (Cycle 158·PO 본인 페인 표현 정합)
> PO 메시지: "영양제 뭐 먹어야 하는지 잘 모르겠더라 그런거 추천도 가능?"
> 평가: **NO_GO** (거대 잠식 + 법적 ↑ + 수익 약함·3중 차단)

## 0. PO 페인 인정

PO 본인 = 영양제 선택 어려움 = 일반적 페인. 인정·기록·but 단독 앱 X.

## 1. 시장 분석 (정직)

- 맞춤형 건기식 시장 ₩4,500억 (2025)
- 식약처 = 2026 AI 디지털 의료기기 인증제 도입 (규제 ↑)
- 정밀 영양 (유전자·장내미생물) 부상

## 2. 경쟁사 매트릭스

| 앱 | 가격 | 패턴 |
|---|---|---|
| 필리 (Pilly) | 영양제 결제 | 유전자·설문 맞춤 = 95% 만족 |
| 필라이즈 (Pillyze) | 무료~Pro | 다이어트·영양제·식단·혈당 통합 |

→ **거대 잠식 매우 강함** (4 앱 + 약국 직접 + 네이버·쿠팡 affiliate).

## 4. 차단 사유 (3중)

3. **수익 약함**: 직접 결제 X·affiliate 거대 잠식·구독 페인 ↓
