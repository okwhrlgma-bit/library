# 왜 결제하는가? — 무료 .exe 있는데 (Cycle 66·도서관장·사서 친화)

> **사서 질문**: "GitHub에서 .exe 무료로 받아 쓸 수 있는데 왜 결제해요?"
> **답**: 가능합니다. **하지만 5분 시간 절감 + 학교운영위 결재 통과 + 법적 책임**은 결제만 가능합니다.

## 1. 무료 사용 가능합니다 (정직)

| 무료 | 가능 |
|---|---|
| `.exe` 다운로드·자가 사용 | ✅ |
| 코드 보기·수정 | ✅ |
| 자관 1관 = 본인 자관 처리 | ✅ |
| offline demo (SAMPLE 12건) | ✅ |
| 자가 빌드 (PyInstaller) | ✅ |

→ **5%의 IT 친숙 사서 = 무료로 충분**.

---

## 2. 하지만 95%는 결제가 더 쌉니다

### 시간 가치 (1순위)

| 자가 사용 | 결제 SaaS |
|---|---|
| NL 인증서 발급 = 1~3일 (정부 사이트·복잡) | 즉시 사용 |
| AI 기능 = Anthropic 가입·미국 카드 등록·BYOK | 통합 결제 |
| 자관 양식 등록 = yaml 직접 편집 | 5분 위저드 |
| 새 버전 = 매번 다운로드·설정 | 자동 알림·1클릭 |
| 에러 = 혼자 해결 | 1일 답변 약속 |

**시간 환산**:
- 자가 = 첫 셋업 5~10시간 + 매월 유지 1시간
- 결제 = 5분 가입 + 매월 자동
- 사서 시급 ₩20,000 × 차이 6시간 = **₩120,000 절감 첫 달 = 월 ₩30K 무료보다 이득**

### 법적 가치 (도서관 RFP 핵심)

| 영역 | 자가 | 결제 |
|---|---|---|
| 세금계산서 | ❌ | ✅ 자동 |
| SLA 99.5% 보장 | ❌ | ✅ |
| 환불 정책 | ❌ | ✅ 30일 무조건 |
| 사고 시 책임 | 사서 본인 | 우리 (사업자) |
| 알라딘 라이선스 | 위반 위험 | 합법 통합 |
| CSAP·ISMS-P | ❌ | ✅ Phase 3 |
| 도서관 RFP 통과 | ❌ | ✅ |
| 자치구 단관 수의계약 | ❌ | ✅ 견적 자동 |

→ **공공·자치구·학교 = "공식 SaaS" 결재 통과 = 결제만 가능**.

### 결재 통과 가치 (학교운영위·자치구·공공)

**시나리오 A — 자가 빌드 (.exe 무료)**:
```
사서 → 학교운영위 → "GitHub에서 받아 쓰겠습니다"
    ↓
운영위 → "누가 책임? 사고 시? 세금계산서?" → 결재 X
```

**시나리오 B — 결제 SaaS**:
```
사서 → 학교운영위 → "공식 SaaS·세금계산서·SLA·환불 보장"
    ↓
운영위 → "공식 사업자·문제 시 명확" → 결재 O
```

→ **결재 = 책임 = 결제**.

## 5. 결제 = 우리 의무

### 우리가 결제 받고 보장하는 것
1. **외부 API 키 통합** = 즉시 사용 (자가 = 1~3일)
2. **AI 기능** = SaaS 제공 (자가 = BYOK)
3. **자동 업데이트** = 1클릭 (자가 = 매번 다운로드)
4. **세금계산서** = 사업자 등록·자동 발급
5. **SLA 99.5%** = 99.5% 미달 시 환불
6. **환불 정책** = 30일 무조건
7. **1일 답변** = GitHub Issues + 이메일
8. **법적 책임** = 우리 사업자 책임 (자가 = 사서 본인)
9. **학교운영위 결재 자료 자동** = PDF·견적·예산표
10. **자치구 단관 수의계약 견적** = 디지털서비스몰 정합

→ **₩30K~/월 = 시간 + 책임 + 결재 통과 = 무료 .exe보다 100배 가치**.
