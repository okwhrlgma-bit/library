# 영업 메시지 페르소나별 매트릭스 (Cycle 61·Part 96 정합)

> 8 ICP 페르소나 × 영업 메시지 = 단일 메시지 ("8분 → 2분") 한계 극복.
> Cycle 61 정직 헤더: 인터뷰 0건·시뮬·가설.

## 핵심 통찰

**시간 절감 단일 메시지 = 5/8 페르소나만 정합**.
- ✅ 정합: P1·P2·P5·P6·P7
- ❌ 부적합: P3 (월급제·시간 ≠ 동기), P4 (학술 RDA·MODS), P8 (경영자 KPI)

→ **5 분기 메시지 매트릭스** 필수.

## 1. 메시지 매트릭스

### P1 김민지 (작은도서관 1인 사서·6,830관)
- **1순위**: "퇴근 시간을 돌려드립니다"
- **2순위**: "야근 1회/주 = 권당 1.5분이 결정"
- **데이터**: 외부 76 보고서·임금 65.2%·감정노동 67.9%·번아웃 +77%
- **채널**: 자치구 단관 수의계약 2천만원·디지털서비스몰·작은도서관 정보누리 (KNU)
- **CTA**: "권당 200원·자치구 일괄 견적 무료"

### P2 박지혜 (학교 사서교사 1인·1,700관·13.9%)
- **1순위**: "자료구입비 3% 효율"
- **2순위**: "신학기 신착 100권 = 5시간 절감"
- **데이터**: 도서관법 §21 자료구입비 3% 의무·학교 일괄 시기 11~12월·2~4월
- **채널**: 학교장터 s2b.kr (사업자 등록 후)·KLA·KLMA
- **CTA**: "월 ₩50,000·학교운영위 결재 견적"

### P3 최지영 (공공도서관 일반 사서·1,296관 다중 사서)
- **1순위**: "민원 ↓ + 오류 ↓" (시간 절감 ≠ 동기·월급제)
- **2순위**: "KOLAS III 종료 마이그레이션 자동"
- **데이터**: 외부 858 보고서 KOLAS III 2026.12.31 종료·D-238 골든윈도우
- **채널**: 공공기관 (CSAP 인증 후·자치구 일괄)
- **CTA**: "KOLAS III 마이그 무료 1관 견적"

### P4 이수진 (대학도서관 사서·400관)
- **1순위**: "RDA·MODS 통합·국산 SaaS"
- **2순위**: "ProQuest 대체·학술 메타데이터 자동"
- **데이터**: 대학도서관 = ProQuest·EBSCO 의존 = 외화·연 수억
- **채널**: KERIS·학술도서관 컨소시엄·도서관장 직접
- **CTA**: "RDA + MODS 무료 시연 30분"

### P5 정현우 (자관 사서·PO 자관·1관·N=1)
- **1순위**: "자관 양식·6년 NPS·즉시 도입"
- **2순위**: "외부 검증 0관·일반화 위험 (정직 헤더)"
- **현실**: PO 본인·결제 권한 ↑·but 외부 검증 X
- **채널**: N/A (PO 자관 PILOT 1관)
- **CTA**: 외부 자관 5관 PILOT 모집 (무료·90일·후기 제공 조건)

### P6 윤서연 (학교 자원봉사·86%·10,500관)
- **1순위**: "자원봉사도 5분 안 입력"
- **2순위**: "사서교사 검수 부담 ↓"
- **데이터**: 학교 사서교사 1명 = 자원봉사 10~20명 검수·시간 ↑
- **채널**: P2 사서교사 경유·학교장터
- **CTA**: "단순 모드 위저드 무료"

### P7 강민호 (책나래·장애인 도서관·5관)
- **1순위**: "책나래·책바다·책이음·책두레·책단비 5종 통합"
- **2순위**: "장애인 도서관 SaaS 1호·점자·DAISY 표준"
- **데이터**: 5 종 + 점자 + DAISY = 사서 1명 = 한계
- **채널**: 자치구·문화재단·복지재단 다중
- **CTA**: "5 종 통합 데모 30분·신뢰 시그널"

### P8 이태경 (도서관장·200관)
- **1순위**: "사서 야근 ↓ = 본인 평판 ↑"
- **2순위**: "민원 ↓·자료구입비 효율"
- **데이터**: 도서관장 = 결제권 ↑·월 30~50만원 직접 결재 가능
- **채널**: KLMA·KLA·도서관 백서 광고 (월 200만원/페이지)
- **CTA**: "분관 2~3개 일괄·연 600만원 견적"
