## 0. 공통 표준

### Subject 형식 (50자 이내)
- 의문형: "{페인} 권당 {시간}분 줄이는 법?"
- 숫자 배치: "KOLAS III 종료 D-{N}일·{혜택}"
- 페르소나 직접 호명: "사서 {역할}님께 - {제안}"

### 본문 구조 (80~100단어)
1. 첫 1줄 = 페인 (사서가 매일 겪는 실제 고통)
2. 둘째 단락 = 솔루션 (우리 SaaS·30초 데모 link)
3. 셋째 단락 = 데이터 (자관 PILOT 1관·6년 NPS·1,228 tests·KOLAS III D-{N})
4. CTA = 5분 데모 영상 또는 무료 PDF 가이드

### 서명 표준
```
조기흠 (사서 출신·1인 PO)
kormarc-auto · 한국 도서관 KORMARC 자동 생성 SaaS
contact@kormarc-auto.example  ·  https://kormarc-auto.kr (예정)
```

### Deliverability (필수·PO 외부 작업)
- SPF + DKIM + DMARC (메일 도메인 인증)
- 회신 가능 주소 (no-reply X)
- 수신 거부 link (PIPA 정합)
- 첫 발송 = 5건/일·점진 확대 (스팸 방지)
