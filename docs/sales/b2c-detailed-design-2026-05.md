# B2C 사서 SaaS — 상세 설계 (Cycle 69·founder-market fit 정합)

> **PO 통찰 (Cycle 69)**: "사서 프로그램 = 내가 필요해서 만든 거·있으면 사서 썼을 듯"
> = founder-market fit·1차 검증 (PO = 사서 = 본인 사용)
> 외부 자관 사서 5명 인터뷰 = 가설 v2 검증.

## 1. founder-market fit 강력 신호

### PO 통찰의 의미
- PO = 사서 출신 = **사용자 = 본인** (희소 우위)
- 자관 PILOT 1관·6년 NPS = 본인 검증
- "있으면 썼을 것" = 결제 의지 + 사용 의지 = 1차 검증

### 우리만 가능한 영업 메시지
> "**사서가 사서를 위해 만든 SaaS**".
> "조기흠 = 자관 6년 운영·KORMARC 학습·매번 답답해서 직접 빌드".

→ 외부 SaaS·외국 SaaS·KOLAS·ALPAS 모두 = founder ≠ 사용자.
→ 우리 = founder = 사용자 = **신뢰 시그널 1순위**.

## 2. B2C 시장 정확 측정

### 한국 사서 분포 (2024 통계·MCST·KLA)
- 공공도서관 사서 = 약 8,000명
- 학교 사서교사 = 약 1,700명 (전임)
- 학교 자원봉사 + 사서 = 약 11,000명 (1인 + 보조)
- 작은도서관 1인 사서 = 약 6,830명 (KNU 미사용 포함)
- 대학·전문 도서관 사서 = 약 3,500명
- 자관·기관 도서관 = 약 500명
- → **TAM 약 31,500명**

### B2C 결제 가능성 (정직 추정)

| 단계 | 사서 수 | 가설 |
|---|---:|---|
| 사서 카페 활동자 (Daum·Naver) | 5,000~10,000 | 적극 사용자 |
| KORMARC 직접 작성 사서 | 15,000+ | 페인 보유 |
| MarcEdit 사용 사서 | 1,000~3,000 | 자가 도구 익숙 |
| **본인 결제 의지 (top 5%)** | 1,500~3,000 | ₩9,900/월 가능 |
| **Founding Member (top 1%)** | 300~600 | ₩4,950/월 즉시 |

→ **SOM 1~3% × ₩9,900 = ₩2.97M~₩9.9M/월** (1~3년 누적).

→ 정직: **시장 작음·but 1인 SaaS = 충분**·자동 클리커보다 작음 1/10.

| **founder = 사용자** | 🟢 매우 강함 | PO 본인 = 1차 검증·외부 5명 = 2차 |
| 사서 B2C 결제 가능 | 🟡 가설·top 5% | 인터뷰 5명 |

### 4-D. 진지 권고

#### 옵션 A: 사서 B2C 즉시 시작 (권고·founder fit)
- **이유**: PO = 사용자·"있으면 썼을 것" = 1차 검증·코드 100% 보유
- **1주 작업**: 사서 카페 글 1~2편 + 5명 인터뷰
- **1개월**: Supabase Auth·PortOne sandbox·30일 trial 활성
- **성공 기준**: 3개월 = 100명 trial·10명 결제 = ₩99K/월 = 시드 매출
- **하방**: 시장 작음·1년 ₩30M/월 한계
- **상방**: founder 신뢰 = 사서 카페 viral = 시장 ↑

#### 옵션 B: 자동 클리커 즉시 시작 (시장)
- **이유**: 시장 100배·결제 의지 ↑
- **1개월 MVP**: PoC = 자영업 리뷰 답변
- **3개월**: 100명 베타·₩100K/월
- **하방**: founder fit 약함·경쟁 (Gumloop·Bardeen·신규)
- **상방**: 글로벌·기업·1인 SaaS 캐시카우 ₩99M+/월

#### 옵션 C: 둘 다 (1인 SaaS 한계)
- **이유**: 헷지·but 외부 901 진단 = "agent pace inflation"
- **권고**: 옵션 A 1개월 + 자동 클리커 = Phase 0 박제만 (현재)

#### 정직 권고 = **옵션 A 1개월 시작 + 자동 클리커 = 박제 (조금씩)**

이유:
1. PO founder fit = 강력 = 1순위
2. 60 사이클 코드 = 즉시 활성 (1개월 = 매출 시도)
3. 자동 클리커 = 시장 ↑·but MVP 1개월·PO founder fit 약함
4. 1개월 후 = 사서 결과 → 자동 클리커 결정

→ **사서 B2C 1개월 = 60 사이클 진짜 가치 활성·자동 클리커 = 결과 후 결정**.
