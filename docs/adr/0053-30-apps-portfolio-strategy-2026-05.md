# ADR 0053 — 30개 단일 기능 앱 포트폴리오 전략 (PO 명령 2026-05-07)

- 상태: Accepted
- 결정자: PO 조기흠
- 일자: 2026-05-07 (Cycle 85)
- 관계: ADR 0052 (코딩 외 활동 0건) 정합·ADR 0050 (B2C 전환) 보완

## PO 메시지 (전문)

> "우리의 목표는 '한 개의 대박 앱'보다 '단일 기능 앱 30개를 빠르게 출시하는 포트폴리오 전략'이 현재 인디 개발자 사이에서 검증된 방식이다. 한 인디 개발자는 30개의 단순 앱 포트폴리오로 12개월 안에 MRR $22,000를 달성했고, 핵심은 '단일 기능으로 버그 없이 빠르게 출시하고, 사용자 피드백으로 다음 앱을 만드는 것'이었다. Claude Code 워크플로우와 결합하면 1주 1앱 배포가 현실적이다. Indie Hackers"

## 결정

**전략 대전환: 단일 대박 앱 (kormarc-auto 단일 집중) → 30개 단일 기능 앱 포트폴리오.**

## 1주 1앱 사이클 (Claude 자율)

```
Day 1 (Mon) — 단일 기능 명확화·spec.md
Day 2 (Tue) — 코드 골격·src/<app>/__init__.py + main.py
Day 3 (Wed) — 핵심 로직 + 단위 테스트 (≥10)
Day 4 (Thu) — UI (Streamlit·CLI·웹·간단)
Day 5 (Fri) — 통합 테스트·ruff·README
Day 6~7 (Sat·Sun) — 정제·docs·다음 앱 시드

Output:
- GitHub repo (commit 누적·PO 미래 push 결정 시)
- README.md (단일 기능·사용법·라이선스 MIT)
- tests/ (≥10 단위·≥3 통합)
- docs/spec.md·learnings.md
```

## 평가축 (각 앱)

| 항목 | 임계값 |
|---|---|
| 단일 기능 명확성 | 1줄 설명 가능 |

| 1주 완성 | 7일 이내 (Day 1~7) |

| 자관 데이터 X | 자관 .mrc·PII = X (헌법 §14) |
