## 12 추가 영역

### A. 결제 채널 분리 (3 분기 매트릭스)
- B2C (사서 개인·자기 돈) = PortOne v2 + 권당 200원 모델
- 학교 (운영비) = 학교장터 s2b.kr 등록 (사업자 등록 후)
- 자치구 (예산) = 디지털서비스몰·수의계약 2천만원 한도 (인증 후)
- 자치구 일괄 (CMS) = 두드림 락인 정면 진입 X

### B. 영업 시기 정합
- 5~10월 = 베타 PILOT·사용자 모집 (현재·D-238 KOLAS3)
- **11~12월 = 학교·자치구 예산 편성 결정적 시점**
- 2~4월 = 봄 신학기 집행·첫 거래
- 9~10월 = 랜딩 + 콜드 메일 시작 필수

### C. PMF 진짜 메트릭 (사용자/추천자/결제자 3 funnel)
- 단일 funnel = 틀림·3 단계 분리 메트릭 필요
- 각 단계 conversion = 다른 마케팅·메시지·KPI

### D. 1인 SaaS 출구 전략
- 사서 .mrc·자관 양식 = 영구 데이터 = SaaS 사라질 때 보호
- 도메인 양도·코드 오픈소스화·데이터 export 자동화 = doc 필수
- "1인 SaaS 신뢰 장벽" 1위 = 출구 전략 명시

### E. 정부 자금 매트릭스 (외부 858 §F)
- AI 바우처 8,900억원·디딤돌 3억원·TIPS 12~15억원
- 소상공인 보험료·자영업자 고용보험 = 사업자 등록 후 즉시
- 매출 1원 + 사업자 등록 = 캐시카우 가속 진입

### F. 세무 임계점
- 일반과세자 = 즉시 세금계산서 발급
- 매출 4,800만원/년 = 간이과세 자동 종료
- 권당 200원·1,200관 평균 200권 = 4,800만원 = 가능 모델

### G. KORMARC 저작권 + NLK 라이선스
- KS X 6006-0:2023.12 = NLK 저작·우리 SaaS = MARC 생성 (저작권 X)
- NLK 시소러스·전거 = API 이용약관 명시 필요

### H. API 종속성 + Disaster Recovery
- NLK·알라딘·data4library = 폐쇄·라이선스 변경 시 영향
- offline mode 있음 (Cycle 13B)·**fallback 정책 doc 0건**

### I. 보안 인증 로드맵
- ISMS-P 자체점검 (즉시·0원) → 정식 (매출 후·200~500만원)
- CSAP (자치구 일괄·1천만원+) → KISA 보안

### J. NPS·후기 자동 수집
- 사서 1명 만족 = 카페·블로그·뉴스레터 전파 (+25%·Part 49)
- 사이클 종료 시 1문항 popup = 미박제

### K. 사서 PILOT 협력 모델
- 외부 자관 5관 = "어떤 조건?" doc 0건
- 사서 평판 리스크 보호 모델 필요

### L. 국제 확장 (중장기)
- 동남아·동북아 = 한국 KORMARC 참고 모델
- MARC21 기반·일부 모듈 재사용 가능

## Consequences

### Positive
- 12 무시 영역 → 매트릭스 박제·다음 사이클 우선순위 명시
- PMF 3-단계 funnel = 진짜 메트릭 분리·외부 858 보고서 정합
- 1인 SaaS 출구 전략 = 신뢰 장벽 1위 해소

### Negative
- 코드 추가 = 적음·doc·매트릭스 위주 (정직 진단 정합)
- 외부 의존 영역 (B·E·I·K·L) = scaffold 포함 X·다음 사이클로

### Neutral
- ADRs: 0044 → 0045
- Cycle: 60 → 61
