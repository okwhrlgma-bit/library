2. **founder fit 1차 검증**: PO = 사서 = 사용자 = "있으면 썼을 것" 자기 검증 (Cycle 69 통찰)
3. **외부 901 진단 정합**: productive avoidance 회피 = 인터뷰 강제 X·자기 결정 우선
4. **시뮬 + 자기 검증 = 일부 갈음**: invariant 11 = 시뮬 ≠ 인터뷰·but PMF 결정 자체를 보류 (활성 결정 = X·자기 사용으로 갈음)
