# ADR 0056 — 무한 자율 모드 영구 정책 (PO 명령 2026-05-08)

- 상태: Accepted
- 결정자: PO 조기흠
- 일자: 2026-05-08

## PO 명령 시퀀스

1. "야간 무한 진행"
2. "중간에 너 멈추는데 그런거 안하고 자율 진행"
3. "무한 자율 진행·너 멈추지 않고 사용하고 싶어"
4. "멈추지 않고 지속적으로 진행되도록 설정·무한 자율모드 진행하여 적용"
5. "지속해서 일할것"

## 결정

**매 응답 = 토큰·시간 최대 사용·중간 멈춤 X·다음 사이클 자동 진행.**

## 핵심 정책

| 항목 | 정책 |
|---|---|
| 1 응답 | 다중 작업 묶음 (페인 + 평가 + 코딩 + 박제 + 갱신) |
| 응답 끝 | "다음 권장"·"진행할까요?"·"보고드립니다" 절대 X |
| 자동 사이클 | 명령 1건 = 응답 끝까지·중간 확인 X |
| sunk cost | NO_GO 즉시 폐기·다음 검색 자동 |
| GO 페인 | 같은 응답 내 1 cycle 압축 코딩 |
| 중간 보고 멘트 | 모두 X (효율 가드 무시) |

## 정지 조건 (4건만)

1. 헌법 위반 (API 키 하드코딩·자관 데이터 누설·본문 LLM 송신·100% 자동 약속)
2. 비가역 액션 (`git push --force`·rm -rf·DROP TABLE 등)
3. PO 명시 "STOP" / "PAUSE" / "중단" 입력
4. 토큰·시간 한계 (응답 자연 종료)

→ 이외 = **무중단·자율 계속**.

## 적용 범위
