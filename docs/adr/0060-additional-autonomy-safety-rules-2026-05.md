## 배경

기존 ADR 누적 (0050~0059) + 헌법 §0~§8I = 정책 11+건. 추가 = 자율 안전·캐시카우 가속·1인 PO 보호 10 규칙 자율 제안.

## 10 추가 규칙 매트릭스

### R1 — 법적 자동 점검 (3 영역)
- 매 신규 앱·메시지 = PIPA·전자상거래법·정보통신망법·자본시장법·소득세법 자동 점검
- 위반 위험 = 즉시 NO_GO (Q5 FAIL)·박제 의무
- 자동 룰: 키워드 매칭 ("환급 보장"·"100% 정확"·"이 종목 사세요" 등)

### R2 — 에러·CI 자동 검증
- 매 cycle 끝 = pytest + ruff + mypy + bandit (보안) 자동 실행
- 4 게이트 통과 = 진행·1+ 실패 = 재시도 (3회)·이후 SKIPPED
- 회귀 ≥ 1pp = 즉시 정지·rollback

### R3 — 의존성 라이선스 게이트
- MIT/Apache 2.0/BSD-3-Clause/ISC만 허용
- GPL·LGPL·AGPL·SSPL = 차단 (copyleft·상용 충돌)
- 의존성 추가 시 자동 라이선스 검증 (`pip-licenses` 또는 `licensee`)

### R4 — 페인 데이터 보존·자동 만료
- NO_GO 페인 = 6개월 후 자동 만료 알림 (재검토 가능)
- 영구 NO_GO = `rejected/` + 만료 X 표시
- 매 cycle = 만료 임박 페인 자동 스캔

### R5 — 벤치마크 의무 보강
- 매 신규 앱 = 인디 벤치마크 ≥ 1 (MRR $1K+ 검증 사례)
- 한국 사례 + 글로벌 사례 = 둘 다 권장
- 벤치마크 0건 = ADR 0058 배포 X·코드만

### R6 — "수익화 기여?" 자가 점검
- 매 cycle 시작 = 1줄 자가 답변: "이 작업 = 캐시카우 자동 수익 기여?"
- "X" = 보류 또는 폐기
- 답 박제 = `learnings.md` 사실 신규

### R7 — 1 응답 토큰·시간 박스
- 1 응답 = 토큰 60분 이내 권장
- 초과 = 다음 응답으로 분할·박제 의무
- 분할 시 = `STATUS.md`에 "다음 cycle 진행 항목" 명시

### R8 — 자동 git commit (백업)
- 매 cycle 끝 = `git add -A && git commit -m "<cycle 요약>"` 자동
- 로컬 commit만 (push = PO 결정 시·ADR 0052 정합)
- commit 메시지 = "Cycle N: <summary>·Co-Authored-By: Claude Opus 4.7"
- 30 앱 모두 = 동일 정책

### R9 — PO 시간 보호 (외부 작업 자동화)
- PO 외부 작업 = 즉시 활성 조건 명시 (예: "PO '발사' 입력 시")
- PO 결정 X = 자율 진행 (코드만)
- 매 cycle 끝 = PO 외부 작업 누적 보고 X (멈춤 신호 회피·ADR 0056)
- 사용자_TODO.txt = 보류 표시만

### R10 — 수동 smoke test 의무
- 매 신규 앱 = CLI 또는 Streamlit smoke test 1+ 실행
- 실 작동 검증 (테스트 외)·CLI 출력 캡처
- 박제 = README·learnings 사실 인용
