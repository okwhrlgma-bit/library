# I-001 — 미국 주식 정보 → 아침 유튜브 숏츠 자동 업로드

## PO 통찰 (2026-05-08)

> "미국 주식시장 영상 자동화도 고려했었음·미국 주식정보를 아침에 유튜브 숏츠로 업로드 느낌"

## 핵심 아이디어

매일 새벽 (한국 시간 06:00·미장 마감 후) = 자동:
1. 미국 주요 지수 (S&P 500·Nasdaq·Dow) 데이터 수집
2. 어제 상승·하락 종목 top 5 (변동률·거래량)
3. 주요 뉴스 요약 (Bloomberg·Reuters·CNBC)
4. LLM = 한국어 스크립트 (60초 숏츠용)
5. TTS = 한국어 음성
6. 자동 영상 (자막·차트·종목 로고)
7. 유튜브 숏츠 자동 업로드 (06:30 KST)

## 단일 기능 후보 (3 변형)

### A. 미국 주식 데이터 → 한국어 숏츠 스크립트 (단순·우리 적합)
- 입력: 날짜·yfinance API
- 출력: 60초 한국어 스크립트 + 차트 데이터
- 영상 자동 생성·TTS·업로드 = 사용자 결정 (옵트인)
- LLM 옵션 (BYOK Claude Sonnet 4.6)

### B. 데이터 + 영상 풀 자동 (복잡)
- yfinance + LLM + TTS + Pillow + ffmpeg + YouTube API
- 외부 API 5+·헌법 §3 timeout 정합
- 1인 PO 운영 부담 ↑

### C. 다른 채널 운영자용 SaaS (B2B)
- 인풋: 채널 운영자 입력 (니치 종목·관심 분야)
- 출력: 매일 자동 스크립트 + 영상 (옵션)
- ARPU $19~49/월 (Opus Clip 벤치마크)

→ **A 권장 (단일 기능·1인 PO 적합·MIT 라이선스 가능)**·B·C는 다음 cycle.
