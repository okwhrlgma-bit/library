# I-002 — 정치 콘텐츠 자동화 (특정 집단 사실 검증·NO_GO 권장·법적 위험)

## PO 통찰 (2026-05-08)

> "미국 주식 숏츠가 가능하면 한국 우익같은 특정 과한 집단 저격하여 자동화도 가능할듯?"

## 가능 해석

1. 정치 양극단 (좌·우) 발언 자동 사실 검증·팩트체크
2. 특정 집단 발언 패턴 분석·클립 자동 생성
3. 공직자 발언 vs 실제 데이터 비교 (정부 통계)
4. 선거 시즌 후보 발언 검증

## 법적 위험 (중대)

| 법령 | 위반 가능성 |
|---|---|
| **명예훼손** (형법 §307·정보통신망법 §70) | 매우 높음 (사실 적시도 처벌·5년 이하 징역) |
| **공직선거법** (§250 허위사실공표) | 매우 높음 (5년 이하 징역) |
| **정보통신망법 §44-7** (불법정보 유통) | 높음 |
| 손해배상 청구 (민법 §750) | 높음 (정치인·집단 동원) |
| 명예훼손 형사 합의금 평균 | ₩500만~5,000만원 |

## 기술적 위험

1. **LLM 환각**: 잘못된 사실 추출 = 명예훼손 책임
2. **편향**: 특정 집단만 저격 = 균형성 위반·SLAPP 소송 위험
3. **유튜브·플랫폼 정책**: 정치 콘텐츠 = 광고 수익 제한 (yellow icon)·계정 정지 위험

## ADR 0055 평가

| 항목 | 점수 |
|---|---|
| 시장 = 정치 콘텐츠 시청자 多·but 수익화 어려움 | 30 |
| 캐시카우 = 광고 제한·구독자 수익 의존 | 20 |
| **Q5** = **법적 위험 매우 높음** | **FAIL** |

## 결정

```
Q5 FAIL = 즉시 NO_GO (다른 점수 무관·ADR 0055 정합)
```

## NO_GO 영구 권장

1. 1인 PO = 명예훼손 소송 = 사업 종료 위험
2. 광고 수익 = 정치 콘텐츠 제한 = 캐시카우 X
3. 균형성 = 양극단 모두 검증해야·사실상 시간 부담 ↑
4. 알고리즘 = 자동 = 환각 = 책임 추궁
5. 1인 PO 사업 = 정치 콘텐츠 = 위험 대비 보상 비대칭

## 대안 (안전 영역)

정치 X·but 인접 캐시카우 가능:
- **공공데이터 시각화** (정치 중립·통계청·국세청·보건복지부 데이터)
- **선거 후보 정보 자동 수집** (중앙선거관리위 공식 데이터·중립)
- **공약 비교** (선거 시즌 단기·but 4~5년 사이클 = 캐시카우 X)
- **국정감사 발언 검색** (국회 공개 데이터·중립 도구)

→ **모두 캐시카우 약함·월정액 어려움·NO_GO 또는 보류**.
