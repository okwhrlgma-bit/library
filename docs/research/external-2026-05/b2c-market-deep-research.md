# kormarc-auto B2C 시장 종합 심층 조사 — 외부 advanced research 박제

> **출처**: PO advanced research 결과 (2026-05-07·D-25 KLA 5/31·D-238 KOLAS III 종료 2026-12-31)

## 0. 핵심 결론

작은도서관 β = 정보누리 무료 출시로 빠르게 잠식·but **KOLAS III 종료 마이그레이션 골든윈도우(2026 Q4)** + **재단 위탁 도서관 α (법인카드)** + **사립 학교도서관 γ (학교운영비)** 페르소나 집중 시 **6주 검증으로 PMF 도달 가능**.

**권당 100원 + 연 19.8만원 하이브리드 가격** = 한국 사서 결제 멘탈 모델 가장 정합.

**사서 시장 협소 가설 = 사실 검증** (활성 ~28,000명 vs 자격증 93,028명·70% 비활동) → **1년 내 일본·대만 수출 PoC** 동시 추진 양면 전략 필수.

## 4. 가격 수용도 검증

### 사서 자비 결제 한도
- 변호사 청년 할인가 (90% off·연 10만 ≈ **월 8천원**)
- 사서 월급 비율 보정 = **월 4,000~6,000원 추정**
- → **월 3만원 자비 결제 어려움**·B2B2C (도서관 결제) 채널 필수

### 권장 가격 구조 (PO 결정 시 활성)
```
[Free]       50권/년 무료
[Pay-per]    권당 100원 (1인 사서 자비)
[Pro 월]     29,700원 (= 빅케이스 Plus)
[Pro 연]     198,000원 (월환산 16,500원·45% 할인)
[Team]       150,000원/월 (다관·5명 사서 공유)
[Enterprise] ~30만원/월 협의

★ 결제수단:
  · 사서 자비: 카카오페이/토스페이먼츠 단건
  · 도서관 본예산: 세금계산서 + 계좌이체
  · 연 결제: 월할 환불 명문화 (한국 No.1 환불국)
```

### 한국 SaaS 결제 패턴
- **한국 = 글로벌 No.1 환불국** (DelightRoom 분석)
- 세금계산서 + 계좌이체 = 공공·기관 표준
- CSAP 인증 = 공공도서관 도입 시 필요 가능
- B2B2C 사례: 위하고T edge·키즈노트·클래스팅

## 8. 5 핵심 가설 (PO 미래 결정 시 검증)

1. **Strong**: KOLAS III 종료 골든윈도우에 채움/다인/KAIT 직접 경쟁 또는 화이트라벨 파트너십 결단으로 B2B2C 진입 가능
2. **Strong**: γ + α = PMF 1차 페르소나·β = 정보누리 잠식 후순위
3. **Medium**: 권당 100원 + 연 19.8만 하이브리드 = 한국 사서 멘탈 모델 정합
4. **Medium-Weak**: 사서 시장 협소 → 1년 내 일본 수출 PoC = SAM 확장 유일 길
5. **Strong (회피)**: 공무원 사서 = 본인카드 결제 불가 = 영원한 비고객·페르소나 의도적 제외
